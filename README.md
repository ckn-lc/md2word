# md2word
# md2word-html
A lightweight single HTML page tool that converts Markdown to Word, improving the efficiency of Markdown format conversion.

## ✨ Features
- Single HTML file, no dependencies, no server required
- Just double-click to open in browser and use
- Paste Markdown content or upload `.md` file
- One-click export as `.docx` Word document
- Support common Markdown syntax

## 🚀 How to use
1. Download the `index.html` file
2. Double-click it to open with your browser 
3. Input Markdown text 
4. Click convert button and download the generated Word file

## 📝 Supported Syntax
✅ Headings
✅ Bold / Italic
✅ Ordered & unordered lists
✅ Tables
✅ Inline code

❌ Not supported: complex LaTeX formulas, Mermaid diagrams

## 🛠 Tech Stack
- HTML + CSS + JavaScript
- docx.js / marked.js（把你实际用的库留下，没用就删掉）
